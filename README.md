# Vite React SPA fixture

A test fixture for Orbitr (EVAL-01c, https://github.com/asquitt/orbitr/issues/1444). A single-page React app built by Vite to `dist/`; the page content is rendered in the browser. Built by a Git-connected Cloudflare Pages project. Seeded from the `orbitr-canary-react-20260223` canary's React and Vite versions. Contains no real business data.
